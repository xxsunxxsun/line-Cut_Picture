# LINE 貼圖製作工具箱

用 AI 做 LINE 貼圖的免費網頁工具，所有圖片處理都在瀏覽器裡完成，不會上傳到伺服器。

| 頁面 | 功能 |
|---|---|
| `index.html` | 主頁、製作流程與規格速查 |
| `prompts.html` | GPT 指令集：上傳照片做角色、8 / 9 張貼圖指令產生器 |
| `sticker.html` | 貼圖裁切：自動偵測位置、格線裁切、智慧置中、去背、ZIP 下載 |
| `cropper.html` | Main（240×240）與 Tab（96×74）圖片製作 |

## 用 GitHub Pages 發佈

1. 把這個資料夾裡的所有檔案上傳到 GitHub repository 的根目錄
2. 到 repository 的 **Settings → Pages**
3. Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save
4. 等一兩分鐘，網址會是 `https://<你的帳號>.github.io/<repository 名稱>/`
