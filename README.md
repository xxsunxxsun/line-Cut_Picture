# 🎨 LINE 貼圖製作工具箱

用 AI 做 LINE 貼圖的免費網頁工具。從 GPT 產圖、自動裁切、去背，到 Main 與 Tab 圖片，一套全部搞定。

所有圖片處理都在你的瀏覽器裡完成，**圖片不會上傳到任何地方**。

---
## 製作流程
```
📝 GPT 指令集  →  ✂️ 貼圖裁切  →  📑 Main & Tab  →  🚀 上架 LINE
```

---

## 📝 GPT 指令集

複製現成的指令貼到 ChatGPT，就能做出一致的角色和整套貼圖。

1. **生成角色**：上傳自己的照片（或用文字描述角色），先做出角色設定圖，調到滿意為止
2. **產生貼圖**：選版面（4×2 共 8 張，或 3×3 九宮格共 9 張）和主題包，也可以自己修改每張的文字和動作，指令會自動更新，按「複製」貼到 ChatGPT
3. **做下一批**：換一組句子再產生，湊滿 16、24、32 或 40 張
4. **出問題時**：角色不像、貼圖黏在一起、字寫錯，都有現成的補救指令可以複製

**小技巧**
- 一張圖只放 8–9 張，每張畫質才夠
- 背景用純淺灰色，不要白色，去背才不會吃掉貼圖的白邊
- 貼圖之間要留空隙，不要格線或外框

---

## ✂️ 貼圖裁切

把 GPT 產生的整張貼圖，一次切成一張一張的 LINE 貼圖。

1. **上傳圖片**：點選、拖曳，或直接 `Ctrl+V` 貼上
2. **確認位置**：上傳後會**自動偵測每張貼圖的位置**並框起來，依照由左到右、由上到下的順序編號
3. **設定輸出**：選尺寸（LINE 貼圖 370×320），視需要勾選「智慧置中」和「背景去背」
4. **一鍵裁切**：按「一鍵裁切全部格子」，再按「全部下載（ZIP）」，檔名會是 `01.png`、`02.png`…

**功能說明**

| 功能 | 說明 |
|---|---|
| 🤖 自動偵測位置 | 自動找出每張貼圖，貼圖靠很近也能分開 |
| 🔲 格線裁切 | 偵測不到時，可以設定欄數、列數或每格大小，拖曳圖片移動格線 |
| 🎯 智慧置中 | 自動找到每格裡的圖案，等比縮放後置中，空白格自動略過 |
| 🪄 背景去背 | 把純色背景變透明，貼圖內部的白色會保留 |
| ✂️ 手動裁切 | 自己拉框，一張一張裁 |

**容許度怎麼設？**
- 淺灰、綠色背景：30–40
- 米白背景、想保留貼圖的白色描邊：調低到 5 左右
- 去背不乾淨就調高，吃到圖案就調低

---

## 📑 Main & Tab 切割

LINE 上架除了貼圖，還需要主要圖片和聊天室標籤。

1. 從裁好的貼圖中挑一張，分別上傳到 **Main** 和 **Tab**
2. 圖片會自動等比縮放置中，不會變形
3. 視需要調整留白、勾選去背
4. 下載 `main.png` 和 `tab.png`

**挑圖建議**
- **Main**：貼圖小舖的封面，挑最能代表這套貼圖的一張
- **Tab**：圖很小，挑臉部特寫、表情明顯的，避免字太多

---

## 📏 LINE 貼圖規格

| 圖片 | 尺寸 | 說明 |
|---|---|---|
| 貼圖 | 最大 370×320 | 8 / 16 / 24 / 32 / 40 張，檔名 `01.png`、`02.png`… |
| 主要圖片 | 240×240 | `main.png` |
| 聊天室標籤 | 96×74 | `tab.png` |

- 格式 PNG、透明背景，每張 1MB 以內
- 寬高為偶數，圖案和邊緣之間留約 10px
