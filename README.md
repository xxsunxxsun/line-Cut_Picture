# 🎨 LINE 貼圖製作工具箱

用 AI 做 LINE 貼圖的免費網頁工具。從 GPT 產圖、自動裁切、去背，到 Main 與 Tab 圖片，一套全部搞定。

所有圖片處理都在你的瀏覽器裡完成，**圖片不會上傳到任何地方**。

---

## 製作流程

```
📝 GPT 指令集  →  ✂️ 貼圖裁切  →  📑 Main & Tab  →  🚀 上架小幫手
```

---

## 📝 GPT 指令集

複製現成的指令貼到 ChatGPT，就能做出一致的角色和整套貼圖。

1. **生成角色**：選畫風（3D Q 版、日系手繪、韓系線條、搞笑漫畫、水彩、黏土、扁平、像素），上傳照片或用文字描述角色，先做出角色設定圖。不知道選什麼可以按「🎲 隨機」
2. **產生貼圖**：選情境（日常用語、生活用語、上班用語、家人長輩、情侶、服務業、節日祝福），每個情境 36 句，分 4 組、每組 9 張九宮格。按「第 1～4 組」切換，複製指令依序貼到同一個 ChatGPT 對話。句子和動作都可以自己改；想做清單沒有的主題，選「✨ 自訂情境」，輸入名稱，GPT 會自動想 36 句
3. **張數**：36 張做完挑最好的 32 張上架（LINE 只接受 8 / 16 / 24 / 32 / 40 張），多的可以做主要圖片和標籤
4. **出問題時**：角色不像、貼圖黏在一起、字寫錯，都有現成的補救指令可以複製

**小技巧**
- 一張圖只放 9 張（九宮格），每張畫質才夠
- 指令會要求「去背的透明 PNG」，GPT 做不到時改用純淺灰色背景，再用裁切工具去背
- 貼圖之間要留空隙，不要格線或外框

---

## ✂️ 貼圖裁切

把 GPT 產生的整張貼圖，一次切成一張一張的 LINE 貼圖。

1. **上傳圖片**：點選、拖曳，或直接 `Ctrl+V` 貼上
2. **確認位置**：上傳後會**自動偵測每張貼圖的位置**並框起來，依照由左到右、由上到下的順序編號
3. **設定輸出**：選尺寸（LINE 貼圖 370×320）。「智慧置中」和「背景去背」預設已開啟（LINE 規定貼圖必須是透明背景）
4. **一鍵裁切**：按「一鍵裁切全部格子」，再按「全部下載（ZIP）」，檔名會是 `01.png`、`02.png`…

**功能說明**

| 功能 | 說明 |
|---|---|
| 🤖 自動偵測位置 | 自動找出每張貼圖，貼圖靠很近也能分開 |
| 🔲 格線裁切 | 偵測不到時，可以設定欄數、列數或每格大小，拖曳圖片移動格線 |
| 🎯 智慧置中 | 自動找到每格裡的圖案，等比縮放後置中，空白格自動略過 |
| 🪄 背景去背 | 把純色背景變透明，貼圖內部的白色會保留 |
| ✂️ 手動裁切 | 自己拉框，一張一張裁 |

**容許度怎麼設？**
- 淺灰、淺藍背景：15（預設值，會保留貼圖的白色描邊）
- 綠幕背景：可以調到 40
- 米白背景：調低到 5 左右
- 去背不乾淨就調高，吃到圖案就調低

---

## 📑 Main & Tab 切割

LINE 上架除了貼圖，還需要主要圖片和聊天室標籤。

1. 從裁好的貼圖中挑一張，分別上傳到 **Main** 和 **Tab**
2. 圖片會自動等比縮放置中，不會變形
3. 視需要調整留白、勾選去背
4. 下載 `main.png` 和 `tab.png`

**挑圖建議**
- **Main**：貼圖小舖的封面，挑最能代表這套貼圖的一張
- **Tab**：圖很小，挑臉部特寫、表情明顯的，避免字太多

---

## 🚀 上架小幫手

把上架 LINE Creators Market 要填的文字資料先準備好。

1. 填**創作者名稱**，輸入英文名字後按「產生版權標示」
2. 填**貼圖名稱**和**說明**（英文必填、中文選填），可以用主題範本快速產生說明
3. 字數會自動檢查（全形字算 2 個字），超過、用了表情符號或英文欄位打了中文都會提醒
4. 照著檢查清單確認一遍
5. 到 Creators Market 上傳 ZIP，每一格按「複製」再貼上，送出審核

填的內容會自動存在你的瀏覽器裡，下次打開還在，不會傳到任何地方。

## 📏 LINE 貼圖規格

| 圖片 | 尺寸 | 說明 |
|---|---|---|
| 貼圖 | 最大 370×320 | 8 / 16 / 24 / 32 / 40 張，檔名 `01.png`、`02.png`… |
| 主要圖片 | 240×240 | `main.png` |
| 聊天室標籤 | 96×74 | `tab.png` |

- 格式 PNG、透明背景，每張 1MB 以內
- 寬高為偶數，圖案和邊緣之間留約 10px

---

## ⚠️ 肖像權提醒

用自己的照片沒問題。用朋友、家人或小孩的照片要先取得對方同意。藝人、名人的照片和別人的角色都不能使用。
